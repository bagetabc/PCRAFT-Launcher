PCRAFT Launcher v1.0.0
=======================

Особенности:
- Полная установка любой версии Minecraft
- Автоматическая загрузка всех библиотек и ассетов
- Настройка имени игрока и памяти
- Кроссплатформенность (Windows/Linux/MacOS)

Требования:
- Python 3.7+
- Java 8 или выше

Установка:
1. Установите Python с python.org
2. Установите Java с adoptium.net
3. Запустите: python pcraft.py

Проблемы:
- Если не скачиваются файлы, проверьте интернет
- При ошибках Java установите Java 8 или 17
- На Linux может потребоваться: sudo apt install openjdk-17-jre
